# Task 022.5: documentPath-based Context Redesign

**ステータス**: 🟡 In Progress
**優先度**: High
**見積もり**: 0.5-1日
**実装者**: AI + Human Review

## 背景

Task 022完了後、ユーザーから重要な設計上の指摘を受けた:

**現在の問題**:

- Contextに`documentPath`から導出可能な冗長な情報が含まれている
- 例: `AllOfContext.parentSchemaName`, `kind`, `index`はすべて`documentPath`から取得可能
- これは実装上の問題であり、本来不要な複雑性を生んでいる

**設計原則**:

- `documentPath`は本来、YAMLのパスを正確に表現すべき
- Contextは`documentPath`の解析を助ける情報を**付加するのみ**

## 現状分析

ほぼすべてのContext情報がdocumentPathから導出可能:

```typescript
// AllOfContext
documentPath: ["components", "schemas", "Extended", "allOf", "0"]
→ parentSchemaName = documentPath[-3] = "Extended"
→ kind = documentPath[-2] = "allOf"
→ index = Number(documentPath[-1]) = 0

// ParameterContext
documentPath: ["paths", "/users", "get", "parameters"]
→ method = documentPath[2] = "get"
→ pathTemplate = documentPath[1] = "/users"

// ResponseContext
documentPath: ["paths", "/users", "get", "responses", "200"]
→ method = documentPath[2] = "get"
→ pathTemplate = documentPath[1] = "/users"
→ statusCode = documentPath[-1] = "200"

// RequestBodyContext
documentPath: ["paths", "/users", "post", "requestBody"]
→ method = documentPath[2] = "post"
→ pathTemplate = documentPath[1] = "/users"
```

**唯一の例外**: `contentType`のみがdocumentPath構造に含まれない（`content`の下の階層）

## 実装メモ

### documentPath構造の標準化

```typescript
// Components配下
["components", "schemas", "User"]
["components", "schemas", "User", "properties", "name"]
["components", "schemas", "Extended", "allOf", "0"]

// Paths配下
["paths", "/users", "get", "parameters"]
["paths", "/users/{id}", "get", "responses", "200"]
["paths", "/users", "post", "requestBody"]
```

### パーサー関数のシグネチャ案

```typescript
export function parseCompositionPath(documentPath: string[]): {
  parentSchemaName: string;
  kind: "allOf" | "anyOf" | "oneOf";
  index: number;
} | null;

export function parseParameterPath(documentPath: string[]): {
  method: string;
  pathTemplate: string;
} | null;

export function parseResponsePath(documentPath: string[]): {
  method: string;
  pathTemplate: string;
  statusCode: string;
} | null;

export function parseRequestBodyPath(documentPath: string[]): {
  method: string;
  pathTemplate: string;
} | null;

export function parseAdditionalPropertiesPath(documentPath: string[]): {
  parentSchemaName: string;
} | null;
```
