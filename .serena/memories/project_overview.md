# OpenAPI XCGen Project Overview

## Purpose

OpenAPI XCGen is a cross-language code generator for OpenAPI specifications. It generates type-safe client code for multiple programming languages from OpenAPI/Swagger specifications.

## Key Features

- Multi-language support (TypeScript, Dart, with more languages planned)
- Modular architecture with independent generators
- Type-safe code generation with runtime validation
- CLI-based tools for each language
- Intermediate Representation (IR) for consistent code generation

## Project Type

- Monorepo using pnpm workspaces
- Node.js ESM modules
- TypeScript-based implementation
- Open source (MIT License)

## Target Users

- Developers who need to generate client SDKs from OpenAPI specifications
- Teams working with multiple programming languages
- Projects requiring type-safe API clients
